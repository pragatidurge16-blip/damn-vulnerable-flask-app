# Damn Vulnerable Flask Application (DVFA)

## Introduction

Damn Vulnerable Flask Application (DVFA) is an intentionally insecure web application developed using **Python Flask**.  
The primary goal of DVFA is to **demonstrate common web application vulnerabilities** in a simple, beginner-friendly way and to show **secure coding fixes** for each vulnerability.

This project is inspired by:
- OWASP Juice Shop
- OWASP Top 10 Web Application Risks

DVFA is **NOT meant for production use**.  
It is designed strictly for:
- Cybersecurity learning
- Secure coding practice
- Vulnerability testing (SAST / DAST / Manual Testing)
- College mini-projects & demonstrations

---

## Objectives

- Demonstrate **real-world web vulnerabilities**
- Provide **clear vulnerable code examples**
- Show **secure fixed implementations**
- Help beginners understand *why* vulnerabilities happen
- Practice OWASP Top 10 concepts practically

---

## Target Audience

- Cybersecurity students
- Web developers learning secure coding
- Pentesters (beginners)
- College project demonstrations
- Security workshops & labs

---

## Technology Stack

| Component | Technology |
|---------|-----------|
| Backend | Python Flask |
| Database | SQLite |
| Session Management | Flask Sessions |
| Frontend | HTML (Jinja Templates) |
| Serialization | JSON, Pickle |
| Security Testing | Manual + Tools |

---

## ⚠️ Warning

> This application is **deliberately insecure**.  
> Do **NOT** deploy on public servers or production environments.

---

## Learning Outcome

After using DVFA, a learner will be able to:
- Identify common vulnerabilities
- Exploit insecure implementations (ethically)
- Understand secure coding fixes
- Map vulnerabilities to OWASP Top 10 categories
